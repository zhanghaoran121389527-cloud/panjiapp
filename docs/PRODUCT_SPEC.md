# 盘迹 产品规格（PRODUCT_SPEC）

## 1. 产品定位

盘迹是一款仅面向中国大陆市场的 iOS 文玩盘玩记录社区。

产品核心：创建玩物 → 持续记录盘玩变化 → 形成成长时间轴 → 后续分享到社区 → 与文玩同好交流。

## 2. 产品原则（所有设计必须遵守）

1. 少字段。
2. 少层级。
3. 少步骤。
4. 图片优先。
5. 不提前实现未来功能。
6. 不为了架构漂亮增加不必要复杂度。
7. 创建一件玩物尽量约 20 秒完成。
8. 一次盘玩记录尽量约 10 秒完成。
9. 玩物详情本质是一件玩物的长期相册日记。
10. 所有功能围绕"记录、展示、交流"服务。

## 3. 当前阶段与范围

- M0：工程底座。
- M1：玩物记录核心闭环。在范围：Dev Login、玩物分类、收藏柜、创建玩物、编辑玩物、盘玩记录、历史补录、成长时间轴、数据持久化、基础异常处理。

**M1 真机验收通过之前禁止开发**：社区、帖子、评论、点赞、关注、消息中心、私信、商城、交易、竞拍、直播、鉴定、AI、会员、等级、积分、勋章、Android、完整 Web 客户端、真实微信登录、真实 Sign in with Apple、真实短信验证码。

> 正式 V1 登录最终为：手机号验证码 + 微信登录 + Sign in with Apple。M1 统一使用 Dev Login。

## 4. M1 核心路径（真实 iPhone 最终验收，20 步）

1 启动盘迹 → 2 Dev Login → 3 设置昵称 → 4 进入收藏柜 → 5 查看空状态 → 6 创建"四座楼狮子头" → 7 选择"核桃" → 8 可添加封面 → 9 创建成功 → 10 自动进入详情 → 11 点击记录第一天 → 12 添加照片 → 13 输入"刚到手，先记录一下。" → 14 保存 → 15 时间轴出现记录 → 16 补录过去日期 → 17 时间轴排序正确 → 18 关闭 App → 19 再次打开 → 20 数据仍然正确存在。

## 5. 技术栈

| 层 | 技术 |
|---|---|
| iOS | Swift + SwiftUI |
| API | NestJS + TypeScript |
| 数据库 | PostgreSQL |
| 正式图片服务 | 腾讯云 COS（M1 用后端本地磁盘，接口契约不变） |
| 正式短信 | 腾讯云 SMS（M1 无短信） |
| Web | Next.js + TypeScript（M1 暂不开发） |
| 接口 | REST API |

## 6. 数据模型

M1 仅允许以下 6 张核心表：users、auth_identities、categories、items、item_records、record_images。
字段级权威定义见 `docs/DATABASE_SCHEMA.md`；接口视角字段语义见 `docs/API_CONTRACT.md` §2。

任何角色如需新增核心表、删除表、修改公共字段语义、修改 ID 策略、修改 API 公共契约，必须提交变更建议，只有总控有权批准。

## 7. API

REST，前缀 `/v1/`。主要接口：

- POST /v1/auth/dev-login
- GET /v1/categories
- POST /v1/items · GET /v1/items · GET /v1/items/:id · PATCH /v1/items/:id · DELETE /v1/items/:id
- POST /v1/items/:itemId/records · GET /v1/items/:itemId/records
- 另有 GET/PATCH /v1/me、POST /v1/uploads（全量定义见 `docs/API_CONTRACT.md`）

任何 Agent 不得自行改变公共 API 契约；变更必须更新 API_CONTRACT.md 并经总控批准。

## 8. 视觉方向

东方极简 + 现代感：暖米白、深茶褐、木棕；图片优先、留白、克制、温润。不做古玩商城、ERP 或传统论坛。
设计 token 见 `docs/DESIGN_SYSTEM.md`（M0-004 交付后定稿）。

## 9. 页面要点

- **收藏柜**：按品类分组陈列；卡片重点显示：封面、名称、盘玩天数；空态引导创建。
- **创建玩物**：必填 = 封面（强引导但允许跳过）、名称、品类；选填 = 子类、入手日期、尺寸/规格、备注；创建成功自动进入详情。
- **盘玩记录**：默认只有照片、一句话、保存；"更多记录项" = 盘玩时长、盘玩方式、记录日期（过去日期即补录）。
- **玩物详情**：核心是大图 + 成长时间轴；空态 CTA"记录第一天"；提供编辑/删除入口。
- **导航形态**：M1 无 TabBar，收藏柜即主页（M2 加社区时再引入 TabBar）。
- **图片查看**：时间轴照片支持点击全屏预览（相册日记固有体验）。
