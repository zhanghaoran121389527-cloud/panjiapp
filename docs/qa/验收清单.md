## 5. 契约核对表（v2.2，QA 评审各提交时逐项勾选）

### 5.1 API（3.1~3.12，前缀一律 `/v1/`）
- 3.1 POST /v1/auth/dev-login：phone 11 位数字；返回 token/user/isNewUser；同号二次 isNewUser=false；M1 无短信
- 3.2 GET /v1/me：需鉴权；无 token → AUTH_REQUIRED
- 3.3 PATCH /v1/me：nickname 1~20 字（A12）；返回更新后 user
- 3.4 GET /v1/categories：固定 5 品类按 sort_order；仅 id+name
- 3.5 GET /v1/items：仅当前用户；createdAt 倒序；含 dayCount（服务端算，无记录=0）
- 3.6 POST /v1/items：name(1~50)/categoryId 必填，其余可 null；201 + 完整 item；封面先 3.10 后 3.6
- 3.7 GET /v1/items/:id：不含 records（时间轴走 3.12）；越权 404
- 3.8 PATCH /v1/items/:id：部分更新；可 null 清空选填；越权 404
- 3.9 DELETE /v1/items/:id：204=逻辑删除（UPDATE deleted_at，WHERE user_id + deleted_at IS NULL）；未命中（不存在/他人/已删除）→ 404；records/images 物理保留；所有 items 查询过滤 deleted_at IS NULL
- 3.10 POST /v1/uploads：需登录（Bearer）；multipart 字段 `file`；jpeg/png/heic/heif/webp；≤10MB；uuid 重命名；相对 URL；`GET /uploads/*` 公开可访问
- 3.11 POST /v1/items/:itemId/records：photoUrls 0~N（落 record_images，sort_order=下标）；content 1~500；duration 1~1440；method ≤20；recordedDate 默认北京今天、过去=补录、晚于今天 → VALIDATION_ERROR（A10）；越权 404
- 3.12 GET /v1/items/:itemId/records：recordedDate 倒序、同日期 createdAt 倒序；越权 404
- 全局：`{code,message}` 错误格式；错误码仅 AUTH_REQUIRED / VALIDATION_ERROR / NOT_FOUND / UPLOAD_TOO_LARGE / UNSUPPORTED_TYPE / INTERNAL；时间戳 ISO 8601 UTC；日期 YYYY-MM-DD 北京时间；可选字段 null

### 5.2 数据库（对照 `docs/DATABASE_SCHEMA.md`）
- 6 表：users / auth_identities / categories / items / item_records / record_images，逐字段一致
- CHECK=A12 全量（nickname 1~20、name 1~50、content 1~500、notes ≤500、size_spec ≤100、subcategory ≤50、method ≤20、duration 1~1440、sort_order ≥0）
- FK：auth→users CASCADE；items→users RESTRICT、items→categories RESTRICT；**records→items RESTRICT**（v2：防物理误删多年记录）；images→records CASCADE（DB 层，非仅实体级）
- 唯一约束：UNIQUE(provider,identifier)、UNIQUE(categories.name)、UNIQUE(record_id,sort_order)（A18）
- 索引：idx_items_user_id、idx_item_records_item_id
- 种子：5 品类固定 UUID 幂等（A17，ON CONFLICT DO NOTHING）；迁移拆分 CreateTables + SeedCategories
- uuid v4 应用侧生成；date 列映射 string；timestamptz UTC；无 DB 层日期 CHECK（禁 CURRENT_DATE）

### 5.3 iOS
- baseURL 经 xcconfig→Info.plist 注入，网络层拼接 `/v1/` 与 `/uploads/`
- token 存 UserDefaults（A7）；401 → 回登录页
- 客户端"今天"与日期上限按北京时间（A13）
- 保存防连点（A14）；仅 iPhone + 竖屏 + iOS 17（B2 裁决）
- 视觉走查依据 DESIGN_SYSTEM（定稿 v1 后对齐）

## 6. 已知限制（契约明示，不作为缺陷）

- 删除/上传失败的物理文件与孤儿文件 M1 不回收（A15、业务规则 8）
- 服务端幂等 M1 不做，由客户端防重兜底（A14）
- M1 不做：记录编辑/删除、社区、真实短信/微信/Apple 登录、品类管理、Android、Web 客户端（业务规则 9）
- 逻辑删除：已删除玩物数据物理保留但对外不可达（404），M1 无恢复/回收站接口（SCHEMA_CHANGE_PROPOSAL-001）
