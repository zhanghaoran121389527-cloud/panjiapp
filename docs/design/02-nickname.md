# 线框 02 · 首次资料（昵称）

- 文件：`docs/design/02-nickname.md`
- 对应接口：`PATCH /v1/me`（API_CONTRACT 3.3）
- 实现：M1-006（iOS）

---

【任务编号】M0-004（UI）

【页面目标】

新用户用 5 秒设置一个昵称，然后直接进入收藏柜。只问一个字段，绝不形成"填资料表"的感觉。

【用户进入页面的原因】

dev-login 返回 `isNewUser=true`，或用户 `nickname` 为空（契约：强制引导设置）。

【信息层级】

1. 一句问候「给自己起个名字」——主标题，口语化。
2. 昵称输入框（唯一输入，1~20 字）。
3. 主按钮「开始盘玩」。
4. 弱说明「以后可在设置中修改」（caption，`textTertiary`）。

【页面布局】

```
┌────────────────────────────┐
│                            │
│                            │
│      给自己起个名字         │  ← itemTitle
│                            │
│  ┌──────────────────────┐  │
│  │ 盘友小王             │  │  ← 输入框（48 高）
│  └──────────────────────┘  │
│                            │
│  ┌──────────────────────┐  │
│  │      开始盘玩        │  │  ← 主按钮
│  └──────────────────────┘  │
│                            │
│   以后可在设置中修改       │  ← caption / textTertiary
└────────────────────────────┘
```

- 内容垂直居中；页面背景 `background`；输入框左右边距 `spaceL`。
- 无导航栏返回键（新用户设置昵称是登录流程的一部分，不提供跳过）。

【主要操作】

「开始盘玩」：`PATCH /v1/me` → 成功后直接进收藏柜。

【次要操作】

无。

【默认状态】

输入框为空，主按钮禁用；输入 ≥1 字后启用。

【空状态】

不适用。

【加载状态】

主按钮内 `ProgressView` + 文案「保存中…」，按钮禁用。

【错误状态】

- 超 20 字：输入即截断（最多输入 20 字），不弹错误。
- 网络失败/`VALIDATION_ERROR`：按钮下方一行 `danger` 文字（`caption`）「没保存成功，请重试」，按钮恢复可用。
- 401：回 Dev Login（全局规范）。

【键盘/手势/iOS交互】

- 打开页面即聚焦输入框（键盘自动升起）。
- 键盘 return 键 = 提交（等同于点「开始盘玩」）。
- 全空格昵称视为空（trim 后为 0 字 → 按钮禁用）。

【需要开发注意事项】

- 本页与登录页是同一 `NavigationStack` 根下的两步；完成后重置到收藏柜根，昵称页不可回退回来（避免登录栈残留）。
- 昵称长度 1~20 字，服务端为准，客户端同规则预校验。
- 设置成功后同步更新本地用户缓存（`GET /v1/me` 数据）。

【明确不做】

跳过昵称按钮、头像上传、性别/年龄/城市等资料字段、"完善资料"进度提示、欢迎页轮播。
