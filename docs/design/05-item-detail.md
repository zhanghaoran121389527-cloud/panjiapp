# 线框 05 · 玩物详情 + 成长时间轴（含空态）

- 文件：`docs/design/05-item-detail.md`
- 对应接口：`GET /v1/items/:id`（3.7）、`GET /v1/items/:itemId/records`（3.12）
- 实现：M1-009（iOS）

---

【任务编号】M0-004（UI）

【页面目标】

这是"一件玩物的长期相册日记"：大图 + 基本信息 + 成长时间轴。不是参数仪表盘。底部常驻「记录今天」，让"记一笔"永远一步可达。

【用户进入页面的原因】

点收藏柜卡片；创建玩物成功后自动进入。

【信息层级】

1. 封面大图。
2. 玩物名 + 品类 + 「第 X 天 · N 次记录」。
3. 「记录今天」常驻主按钮（底部）。
4. 成长时间轴（时间倒序，照片优先）。
5. 导航栏「编辑」入口（最弱）。

【页面布局】

```
┌────────────────────────────┐
│  ←            编辑         │  ← 导航栏（标题=玩物名，inline）
│ ┌────────────────────────┐ │
│ │                        │ │  ← 封面 1:1 大图，radiusL；
│ │       [封面大图]        │ │     无封面=accentSoft+首字
│ └────────────────────────┘ │
│  四座楼狮子头              │  ← itemTitle
│  (核桃)  盘玩第 12 天 · 8 次记录 │ ← 静态品类 chip + secondary
│                            │
│  成长时间轴                │  ← heading
│  │ 1月12日                 │  ← caption / textSecondary
│  ● ┌────────────────────┐ │
│  │ │ [图][图] →          │ │  ← 96 缩略图横滚行
│  │ │ 今天盘得发亮        │ │  ← body
│  │ │ 30 分钟 · 手套盘    │ │  ← caption（无则不显示）
│  │ └────────────────────┘ │
│  │ 1月3日                 │
│  ● ┌────────────────────┐ │
│  │ │ 刚到手，先记录一下。 │ │  ← 无照片的纯文字条目
│  │ └────────────────────┘ │
│                            │
│ ┌────────────────────────┐ │
│ │       记录今天          │ │  ← 底部常驻主按钮（安全区上）
│ └────────────────────────┘ │
└────────────────────────────┘
```

- 时间轴：左侧竖线（`divider` 2pt）+ 节点圆点（`accent` 8pt）；条目卡片 `surface`。
- 照片 0 张：纯文字条目（如上面 1月3日）；1~N 张：缩略图横向滚动行在文字上方。
- 日期标签：`recordedDate==北京今天` →「今天」；同年 →「M月d日」；跨年 →「yyyy年M月d日」。
- meta 行只显示已填项：`30 分钟 · 手套盘`，全空则整行隐藏。

【主要操作】

- 「记录今天」：打开记录 sheet（线框 06）。
- 无记录时按钮文案变「记录第一天」（与空态 CTA 一致），打开同一个记录 sheet。

【次要操作】

- 导航栏「编辑」：进编辑玩物（线框 07，含删除入口）。
- 点时间轴照片：全屏查看（黑色底全屏 sheet，左右滑动切图，下滑/点关闭按钮关闭）。
- 时间轴下拉刷新。

【默认状态】

有记录：时间轴按 `recordedDate` 倒序、同日期 `createdAt` 倒序（接口已排序，客户端保持原序渲染）。头部信息：`dayCount>0` →「盘玩第 X 天」；`==0` →「尚未开始盘玩」；记录数 →「N 次记录」（0 次则隐藏本行或显示「0 次记录」）。

【空状态】

```
        ( camera )        ← accentSoft 圆底 96 + SF Symbol
      还没有记录          ← heading
 拍下第一张照片，记下它的起点  ← secondary
 ┌──────────────────────┐
 │     记录第一天        │  ← 主按钮（宽 240）
 └──────────────────────┘
```

- 位于「成长时间轴」标题下方，居中；与底部常驻按钮同为「记录第一天」，两处均可点。
- 空态不显示左侧时间轴线。

【加载状态】

首次进入：封面区与大图位置显示 `surface` 色块占位；时间轴区显示 3 个骨架条目（色块呼吸动画）。底部按钮可用性不受影响。

【错误状态】

- 详情或记录拉取失败：整页错误态（「出了点问题」+ 重试），保留返回能力；重试重新拉取。
- `NOT_FOUND`（玩物已被删除）：提示「这件玩物不存在或已被删除」，返回收藏柜并刷新列表。
- 图片加载失败：见 `08-states.md`。
- 保存成功后由记录页关闭回本页并即时刷新（M1-009 验收 ④）。

【键盘/手势/iOS交互】

- 大图不遮挡状态栏信息；上滑时封面随内容滚动（不做视差）。
- 点封面大图 = 无操作（预览只在时间轴照片上）。
- 全屏照片查看用系统交互习惯：左右滑切换、下滑关闭。

【需要开发注意事项】

- 详情与记录是两个接口，分别请求；进入页面并行拉取，任一失败按错误状态处理。
- 记录保存后回详情：直接刷新 records 与 item（dayCount 会变），不用"本地乐观插入再对账"（简单优先）。
- 时间轴只读：M1 不支持记录编辑/删除，条目不提供长按菜单。
- 「第 X 天」中 X 用服务端 `dayCount`，禁止客户端自算（契约 §4.1）。

【明确不做】

记录编辑/删除、长按评论/点赞、参数仪表盘（克重/包浆度等指标表）、统计图表、分享/导出时间轴、筛选按月份、深色模式。
