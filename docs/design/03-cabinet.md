# 线框 03 · 收藏柜（含空状态）

- 文件：`docs/design/03-cabinet.md`
- 对应接口：`GET /v1/items`（API_CONTRACT 3.5）
- 实现：M1-007（iOS）

---

【任务编号】M0-004（UI）

【页面目标】

登录后第一眼就是自己的"收藏柜"：按品类分组陈列玩物，像摆柜子一样。每件玩物只看三样：封面、名称、盘玩天数。M1 本页即主页（无 TabBar）。

【用户进入页面的原因】

登录/昵称设置完成后的默认主页；收藏柜内创建、返回详情时回到本页。

【信息层级】

1. 大标题「收藏柜」＋ 右上角「+」创建入口。
2. 品类分组（核桃 / 菩提 / 木质 / 玉石 / 其他，按 sort_order）。
3. 组内卡片：封面（第一优先）→ 名称 → 盘玩天数。

【页面布局】

```
┌────────────────────────────┐
│ 收藏柜                 +   │  ← 导航大标题 + 创建
│                            │
│  核桃                      │  ← heading（分组头，左对齐）
│  ┌──────────┐ ┌──────────┐ │
│  │ [封面1:1]│ │ [首字占位]│ │  ← 卡片：封面 / accentSoft+首字
│  │          │ │   星     │ │
│  ├──────────┤ ├──────────┤ │
│  │四座楼狮子头│ │星月菩提  │ │  ← heading 1 行截断
│  │盘玩 12 天 │ │尚未盘玩  │ │  ← caption / textSecondary
│  └──────────┘ └──────────┘ │
│                            │
│  木质                      │
│  ┌──────────┐              │
│  │ [封面1:1]│              │
│  ├──────────┤              │
│  │小叶紫檀手串│             │
│  │盘玩 3 天  │             │
│  └──────────┘              │
└────────────────────────────┘
```

- 两列网格（`LazyVGrid`，列间距/行间距 `spaceM`，页边距 `spaceL`）；封面 1:1 顶到卡片上沿，名称与天数在封面下方。
- 分组仅显示有玩物的品类；组内按 `createdAt` 倒序（接口已排序）；品类间按 `sort_order`。
- 无封面的卡片：`accentSoft` 底 + 玩物名首字（heading、`textSecondary`）居中。

【主要操作】

- 右上角「+」：打开创建玩物（sheet）。
- 点卡片：进玩物详情。

【次要操作】

- 下拉刷新（`.refreshable`）。

【默认状态】

有玩物：按上述分组陈列。天数文案：`dayCount==0` →「尚未盘玩」；`==1` →「盘玩 1 天」；`>1` →「盘玩 N 天」。

【空状态】

```
        ( tray )          ← accentSoft 圆底 96 + SF Symbol tray / accent
     还没有玩物            ← heading
 创建第一件玩物，开始记录它的变化  ← secondary / textSecondary
 ┌──────────────────────┐
 │   创建第一件玩物      │  ← 主按钮（宽 240）
 └──────────────────────┘
```

- 垂直居中；CTA 与右上角「+」行为一致（打开创建 sheet）。
- 空态下隐藏右上角「+」？——不隐藏，两处入口都保留（用户习惯 iOS 右上角加号）。

【加载状态】

首次进入：4 个骨架卡片（`surface` 色块 + 轻微透明度呼吸动画 0.6→1.0，1s 循环），布局同网格。骨架不含文字线条（克制）。

【错误状态】

- 首次加载失败：整页错误态（图标 `wifi.slash`/`exclamationmark.triangle` + 「出了点问题」/「网络不可用」+ 重试按钮），见 `08-states.md`。
- 已有列表后刷新失败：顶部细横幅「刷新失败，下拉重试」（`dangerSoft` 底 + `danger` 字，自动消失或下拉重试后消失），不清空已显示内容。

【键盘/手势/iOS交互】

- 大标题用系统 `navigationTitle(.largeTitle)` 行为（上滑收起为小标题）。
- 卡片按压反馈：轻微缩放/变暗（`surfacePressed`）。
- 下拉刷新阈值与系统一致。

【需要开发注意事项】

- 分组用 `categoryId` 与 `GET /v1/categories`（sort_order）联表在客户端完成；分组顺序固定核桃→菩提→木质→玉石→其他。
- `dayCount` 直接用服务端返回值，客户端不计算（契约 §4.1）。
- 卡片封面 `coverImageUrl` 为相对路径，拼接 baseURL 加载；加载失败静默降级为首字占位（见 `08-states.md`）。
- 收藏柜是导航根页面；从详情返回时列表如有变化（创建/删除）需同步刷新。

【明确不做】

无 TabBar（收藏柜即主页）；搜索、排序切换、批量管理、品类折叠、玩物数量统计、"最近盘玩"排序、深色模式。
