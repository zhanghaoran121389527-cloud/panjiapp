# 线框 01 · Dev Login

- 文件：`docs/design/01-dev-login.md`
- 对应接口：`POST /v1/auth/dev-login`（API_CONTRACT 3.1）
- 实现：M1-006（iOS）

---

【任务编号】M0-004（UI）

【页面目标】

让开发期用户用手机号一步进入盘迹（M1 无短信验证），并把"这是开发版登录"说清楚，不给正式登录错觉。

【用户进入页面的原因】

启动 App 且本地无有效登录态（首次启动、token 失效/被清、401 后）。

【信息层级】

1. 品牌圆标（accent 圆底 +「盘」）＋ 品牌名「盘迹」——第一眼。
2. 一句副标题「记录每一次盘玩」。
3. 手机号输入框（唯一输入）。
4. 主按钮「进入盘迹」。
5. 开发说明脚注（最弱：「M1 开发版：输入任意手机号即可，不发验证码」）。

【页面布局】

```
┌────────────────────────────┐
│                            │
│          ( 盘 )            │  ← 88×88 accent 圆标，display「盘」
│                            │
│           盘迹             │  ← display
│     记录每一次盘玩         │  ← secondary / textSecondary
│                            │
│  ┌──────────────────────┐  │
│  │ 13800138000          │  │  ← 输入框（48 高，keyboardType 数字）
│  └──────────────────────┘  │
│                            │
│  ┌──────────────────────┐  │
│  │      进入盘迹        │  │  ← 主按钮（52 高，全宽）
│  └──────────────────────┘  │
│                            │
│  M1 开发版：输入任意手机号   │  ← caption / textTertiary，居中
│  即可，不发验证码          │
└────────────────────────────┘
```

- 上下留白 `spaceXXXL`；内容垂直居中偏上；页面背景 `background`。
- 手机号框显示 11 位校验状态：不足 11 位 → 主按钮禁用。

【主要操作】

「进入盘迹」：调 dev-login → 成功存 token（UserDefaults）→ `isNewUser=true` 或 `nickname` 为空 → 进昵称页；否则直接进收藏柜。

【次要操作】

无。M1 登录页不放"注册/忘记密码/协议"等任何次入口（不适用）。

【默认状态】

- 首次：手机号为空，主按钮禁用。
- 之后（开发便利）：自动回填上次成功登录的手机号（UserDefaults），主按钮可用。

【空状态】

不适用（无列表）。

【加载状态】

主按钮内 `ProgressView` + 文案「进入中…」，按钮禁用、输入框失焦。

【错误状态】

- 格式错（<11 位）：按钮保持禁用即可，不弹错误。
- 网络失败/超时/`INTERNAL`：按钮下方出现一行 `danger` 文字（`caption`）：「网络不太顺畅，请重试」，按钮恢复可用；再次点击重试。不弹系统弹窗。
- 401 等认证异常按全局规范处理（见 `08-states.md`）。

【键盘/手势/iOS交互】

- `keyboardType(.numberPad)`；输入框加工具栏「完成」键收起键盘。
- 点主按钮即收起键盘再请求。
- 不做第三方键盘、不做验证码倒计时（M1 无短信）。

【需要开发注意事项】

- token 持久化：UserDefaults（裁决 A7）；启动时若有 token 用 `GET /v1/me` 恢复，失败且 401 才回本页。
- 手机号仅作 dev 身份标识，本地可存"上次手机号"，但不做账号密码语义。
- 与 M0-003 的 RootView 占位页替换关系：M1-006 用本页替换 RootView。

【明确不做】

真实短信验证码、微信/Apple 登录、图形验证码、注册/找回密码、用户协议页、隐私政策页、深色模式配色。
