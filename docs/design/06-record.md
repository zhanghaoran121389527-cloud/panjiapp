# 线框 06 · 记录今天 + 历史补录

- 文件：`docs/design/06-record.md`
- 对应接口：`POST /v1/items/:itemId/records`（3.11）、`POST /v1/uploads`（3.10）
- 实现：M1-010（iOS）

---

【任务编号】M0-004（UI）

【页面目标】

约 10 秒完成一次盘玩记录。默认表单只有三样：照片、一句话、保存——"拍一下，记一句，就好了"。历史补录 = 同页「更多记录项」里把日期改成过去，不另做页面。

【用户进入页面的原因】

玩物详情点「记录今天 / 记录第一天」。

【信息层级】

1. 照片区（0~N 张，可选，可跳过）。
2. 一句话（唯一必填，打开即聚焦）。
3. 「保存」常驻主按钮。
4. 「更多记录项」折叠区（记录日期 / 盘玩时长 / 盘玩方式）——默认收起，弱化。

【页面布局】

```
┌────────────────────────────┐
│  ✕         记录今天        │  ← 全屏 sheet 导航栏
│                            │
│ ┌──────┐ ┌──────┐ ┌──────┐ │
│ │ +照片│ │ [图] │ │ [图] │ │  ← 3 列网格，首格=添加格
│ └──────┘ └──────┘ └──────┘ │     （accentSoft 底 + camera）
│                            │
│  ┌──────────────────────┐  │
│  │ 今天怎么样？         │  │  ← 一句话（多行，打开即聚焦）
│  └──────────────────────┘  │
│                            │
│  ▸ 更多记录项              │  ← 折叠行（默认收起）
│                            │
│  ┌──────────────────────┐  │
│  │         保存         │  │  ← 主按钮（底部安全区上）
│  └──────────────────────┘  │
└────────────────────────────┘
```

「更多记录项」展开后（追加在折叠行下方，同页）：

```
│  ▾ 更多记录项              │
│  记录日期      今天    >  │  ← 点开日期选择（上限=北京今天）
│  盘玩时长   [-] 30 [+]    │  ← Stepper，0=未记录
│  盘玩方式  如：手套盘      │  ← 文本 ≤20
```

【主要操作】

「保存」：有照片则按选择顺序逐张上传（顺序即 `photoUrls` 数组顺序）→ `POST /v1/items/:itemId/records` → 成功 toast「已保存」+ 轻触感反馈 → 自动关闭 sheet，详情即时刷新。

【次要操作】

- 右上「✕」：关闭不保存；有未保存内容时系统确认（「放弃这次记录？」放弃/继续编辑）。
- 「更多记录项」展开/收起：`withAnimation(.easeInOut(duration: 0.2))`，默认收起。
- 记录日期改过去 = 补录（上限=北京今天，未来日期灰置不可选）；改回「今天」即普通记录。
- 已选照片缩略图右上角「×」移除该张；选择顺序即展示顺序（M1 不做拖拽排序）。

【默认状态】

- 打开即聚焦「一句话」输入（键盘升起），这是 10 秒目标的起点。
- 「保存」禁用直到一句话非空（trim 后 ≥1 字）。
- 照片 0 张可保存（契约允许 0~N）；添加格始终在网格最后。

【空状态】

不适用（表单页）。

【加载状态】

「保存」按钮内 `ProgressView` + 文案「保存中…」，按钮禁用（防连点，裁决 A14）。照片上传中同样保持禁用。

【错误状态】

- 照片上传失败（超 10MB / 格式 / 网络）：对应缩略图置灰 + 行内提示「这张没传成功，点按重试」，点击重传该张；不阻塞继续选择其他照片。
- 保存失败：主按钮上方 `danger` 提示行（「没保存成功，请重试」/「网络不太顺畅，请重试」），全部已填内容与已选照片保留，按钮恢复可用；重试只重发剩余未完成步骤。
- 一句话超 500 字：输入即截断。
- 服务端 `VALIDATION_ERROR`（如 recordedDate 晚于今天）：显示后端 message，日期选择回退为今天。

【键盘/手势/iOS交互】

- 照片选择用系统 `PhotosPicker`（多选，顺序保持选择顺序）。
- 点添加格 → 键盘自动收起 → 打开照片选择；返回后键盘不自动再弹（避免跳动）。
- 一句话多行输入（`axis: .vertical`），高随内容增长。
- 日期选择用系统 `DatePicker`（`.graphical` 或 `.compact`，iOS 按习惯），上限=北京今天（裁决 A10/A13）。
- 保存成功轻触感反馈（success haptic）。

【需要开发注意事项】

- 请求体：`photoUrls` 为上传返回的相对 URL 数组（下标顺序=展示顺序）；`recordedDate` 默认北京今天，未动过日期选择器就不传（走服务端默认），动过则传所选值。
- 补录与正常记录完全同一接口（3.11），无 UI 差异。
- 时长 `durationMinutes`：0 或未动 = `null`；范围 1~1440，UI 步进 5（显示「未记录」当 0）。
- 保存成功后由本页 dismiss，详情页刷新（M1-010 验收 ④）。

【明确不做】

记录编辑/删除、照片滤镜/裁剪/标注、拖拽排序、语音输入、标签、心情/状态选择、连拍倒计时、补录专用页面。
