# 线框 04 · 创建玩物（含品类选择）

- 文件：`docs/design/04-create-item.md`
- 对应接口：`POST /v1/items`（3.6）、`POST /v1/uploads`（3.10）
- 实现：M1-008（iOS）

---

【任务编号】M0-004（UI）

【页面目标】

约 20 秒、≤3 步创建一件玩物。必填只有名称 + 品类；封面强引导但可跳过；选填全部默认折叠。创建成功自动进入详情。

【用户进入页面的原因】

收藏柜右上角「+」或空态 CTA「创建第一件玩物」。

【信息层级】

1. 封面（大图区，强引导但可跳过）——第一视觉。
2. 名称（必填）→ 品类（必填，5 芯片一行）。
3. 「更多信息」折叠区（选填：子类/入手日期/尺寸规格/备注）。
4. 底部主按钮「创建」。

【页面布局】

```
┌────────────────────────────┐
│  取消        新建玩物       │  ← sheet 导航栏
│  ┌──────────────────────┐  │
│  │      [ camera ]      │  │  ← 封面区：accentSoft 底，高 200
│  │      添加封面         │  │     radiusL；选中后图片 fill +
│  │      (可跳过)         │  │     右下角「更换」小按钮
│  └──────────────────────┘  │
│  名称                      │  ← caption 标签
│  ┌──────────────────────┐  │
│  │ 如：四座楼狮子头      │  │  ← 输入框，打开即聚焦
│  └──────────────────────┘  │
│  品类                      │
│  (核桃)(菩提)(木质)(玉石)(其他) ← 5 芯片，单选，wrap
│                            │
│  ▸ 更多信息                │  ← 折叠行（默认收起）
│                            │
│  ┌──────────────────────┐  │
│  │         创建         │  │  ← 主按钮（底部安全区上）
│  └──────────────────────┘  │
└────────────────────────────┘
```

【主要操作】

「创建」：有封面则先上传拿相对 URL（失败见错误状态）→ `POST /v1/items` → 成功后关闭 sheet 并自动 push 详情页。

【次要操作】

- 「取消」：关闭 sheet（不保存；已选封面不上传）。
- 封面「更换」：重开照片选择；「移除」（小字 ghost，选中后出现）：清空封面。
- 「更多信息」展开：子类（文本 ≤50）、入手日期（DatePicker，上限=北京今天）、尺寸/规格（文本 ≤100）、备注（多行 ≤500）。

【默认状态】

- 名称空 + 未选品类 → 「创建」禁用。
- 「更多信息」默认折叠，全部选填字段为空。
- 打开页面即聚焦名称输入（键盘升起），这是 20 秒目标的起点。

【空状态】

不适用（表单页）。

【加载状态】

「创建」按钮内 `ProgressView` + 文案「创建中…」，按钮禁用（防连点，裁决 A14）；封面上传中同样文案「上传封面中…」并禁用「创建」。

【错误状态】

- 封面上传失败（`UPLOAD_TOO_LARGE`/`UNSUPPORTED_TYPE`/网络）：封面区下方一行 `danger` `caption` 提示（「图片超过 10MB，请换一张」/「暂不支持该图片格式」/「网络不太顺畅，请重试」），已填内容全部保留，可重试或跳过封面继续创建。
- 创建失败：主按钮上方出现 `danger` 提示行 + 按钮恢复可用；重试仅重发创建请求。
- 名称超 50 字：输入即截断。

【键盘/手势/iOS交互】

- 照片选择用系统 `PhotosPicker`（多选相册照，iOS 17 API）；封面单选。
- 点封面区任意位置 → 打开照片选择；键盘先收起。
- 名称 return → 跳到品类（无键盘事件，仅收起）。
- 品类芯片单指点击即选中，再次点击不取消（品类必选，无"不选"态）。
- 备注多行输入最小高 88，自动增高。

【需要开发注意事项】

- 品类数据来自 `GET /v1/categories`（固定 5 个，顺序 sort_order）；芯片即全部品类，无需二级选择。
- 创建请求体：`name`、`categoryId` 必填；`coverImageUrl` 无则 `null`；选填字段无值一律 `null`（契约：不用空串）。
- 创建成功拿到 item 后直接 push `ItemDetailView(itemId:)`，同时刷新收藏柜数据（M1-008 验收 ②）。
- 表单校验：trim 后名称 1~50 字；品类必选；其余不校验（服务端为准）。

【明确不做】

子类字典选择（自由文本）；封面拍照/裁剪/滤镜（只用系统相册）；多件批量创建；模板/预设名称；创建后分享。

---

### 设计简化建议（提请总控确认）

**品类选择不单独成页**：品类固定只有 5 个，本线框将其做成创建页内 5 芯片（1 击完成，少一次页面跳转），支撑"≤3 步"与 20 秒目标。若总控保留独立品类选择页，则：以 sheet 呈现，标题「选择品类」，5 行列表（每行：品类名 + 选中 `checkmark`，`accent` 色），点击即选中并自动关闭返回创建页。二选一，建议采纳前者（已写入本线框主方案）。
