## 1. 完成内容

- **创建表单**（`CreateItemView.swift`，sheet 呈现）：封面区（accentSoft 高 200、camera+「添加封面」+「（可跳过）」；选中后 fill 预览 + 右下「更换」+ 右上「移除」）→ 名称（打开即聚焦、1~50 截断）→ 品类（5 芯片流式换行，单选不可取消，B4 裁决）→「更多信息」折叠（子类 ≤50 / 入手日期（上限=北京时间今天，可清除）/ 尺寸规格 ≤100 / 备注多行 ≤500，0.2s 展开动画）→ 底部主按钮「创建」（安全区上）。
- **提交流程**（`CreateItemStore.swift`）：有封面先 `POST /v1/uploads`（multipart，字段 `file`，MIME 从文件头推断 jpeg/png/heic/heif/webp）拿相对 URL 再 `POST /v1/items`（coverImageUrl 相对 URL 或 null；选填字段 trim 空一律 null——契约空值规则）；上传成功记下 URL，**创建失败重试不重复上传**（08-states D）；防连点（提交中禁用，裁决 A14）；401 → signOut。
- **创建后自动进详情**：收藏柜 sheet 关闭 → push 占位详情（`ItemDetailPlaceholderView`，M1-009 替换）→ 同时回刷收藏柜列表（线框 03 注意事项）。
- **照片选择**：系统 `PhotosPicker`（原生，无第三方库），单选封面，`loadTransferable(type: Data.self)` 取原始数据（HEIC 原样上传，契约 3.10 白名单支持）。
- **错误状态**：封面上传失败→封面区下方 danger 提示（08-states B 表文案），可移除封面跳过继续创建；创建失败→主按钮上方 danger 提示，表单内容全部保留；品类加载失败→行内错误 + 「重试」。
