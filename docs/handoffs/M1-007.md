## 1. 完成内容

- **收藏柜主页**（`Features/Items/CabinetView.swift`，替换 CabinetPlaceholderView）：导航大标题「收藏柜」、两列网格（`LazyVGrid`，间距 `spaceM`、页边距 `spaceL`）、品类分组头（heading，仅含有玩物的品类，顺序按 sort_order）、组内按 createdAt 倒序（服务端序）。
- **卡片**（`ItemCardView.swift`）：封面 1:1（`AsyncImage`，缺失/加载中/失败一律静默降级为 accentSoft 首字占位，08-states C）+ 名称（heading，1 行截断）+ 盘玩天数（caption：0→「尚未盘玩」、1→「盘玩 1 天」、>1→「盘玩 N 天」）；卡片 surface+divider+cardShadow。
- **空态**（线框 03）：tray 圆底图标 + 「还没有玩物」+ 说明 + CTA「创建第一件玩物」（宽 240）；右上角「+」与 CTA 行为一致（当前打开临时占位 sheet，M1-008 替换为真实创建页）。
- **下拉刷新**（`.refreshable`）：成功替换数据；失败保留内容仅顶部横幅「刷新失败，下拉重试」（dangerSoft，3s 自动消失）。
- **首载骨架**（08-states）：4 个 surface 色块 0.6→1.0 呼吸动画，无文字线条。
- **整页错误态**（08-states A）：wifi.slash/三角形 + 标题/说明 + 「重试」（宽 240）；401 → `session.signOut()` 回登录。
- **DEBUG-only「开发：切换账号」**（裁决 B8，QA B18 冒烟）：`#if DEBUG` 包裹的 toolbar 按钮 → `signOut()`；Release 构建不编译该入口（验收⑥）。
- **数据层**（`CabinetStore.swift`）：`async let` 并发拉取 `/categories`+`/items`，客户端 `compactMap` 分组；View 不直接发请求、不自拼 URL（图片经 `APIClient.imageURL(for:)` 解析，裁决 A3）。
