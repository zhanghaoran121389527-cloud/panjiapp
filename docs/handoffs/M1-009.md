- **空态**（线框 05）：camera 圆底 +「还没有记录」+「拍下第一张照片，记下它的起点」+ CTA「记录第一天」（与底部常驻按钮同入口）；空态不显示时间轴线。

- **错误态**：首载失败整页错误+重试；`NOT_FOUND` →「这件玩物不存在或已被删除」+ 返回收藏柜（返回自动回刷列表）；刷新失败保留内容 + 横幅；401 → signOut。

- **接线点**（占位 sheet，后续任务替换）：「记录今天/记录第一天」→ M1-010；「编辑」→ M1-011；记录 sheet `onDismiss` 已挂 `store.refresh()`（验收④「记录保存后回详情即时刷新」链路就绪）。

## 4. 使用 API（契约 v2.3）

| 接口 | 用途 |
|---|---|
| `GET /v1/items/:id` | 详情（含 dayCount，不含 records） |
| `GET /v1/items/:itemId/records` | 时间轴（photoUrls 多图、recordedDate 倒序） |
| `GET /v1/categories` | 品类名映射（头部 chip） |

- 三接口 `async let` 并行拉取；401 → signOut；404（详情/记录）→ notFound 态。

## 9. 异常状态

| 场景 | 表现 |
|---|---|
| 首载中 | 1 大图 + 3 条目骨架（色块呼吸，无文字线条） |
| 首载失败 | 整页错误态 + 重试（网络/服务器分文案图标） |
| NOT_FOUND（已删除） | 「这件玩物不存在或已被删除」+「返回收藏柜」（返回自动回刷） |
| 刷新失败（已有内容） | dangerSoft 横幅「刷新失败，下拉重试」，内容保留 |
| 401 | 清 token 回登录 |
| 封面/缩略图失败 | 封面静默首字占位；缩略图「加载失败」点击重试 |
