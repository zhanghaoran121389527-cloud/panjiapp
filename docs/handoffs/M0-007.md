# M0-007 交接说明（Backend：lint 配置修复）

## 【任务】

M0-007【BE】Backend lint 配置修复（READY → REVIEW）。

## 【失败复现】

QA M0-006 现场复核命令（`apps/api` 下）：

```
node node_modules/eslint/bin/eslint.js "src/**/*.ts" "test/**/*.ts" "scripts/**/*.ts"
→ Oops! Something went wrong! :(
→ ESLint: 9.39.5
→ No files matching the pattern "scripts/**/*.ts" were found.
→ exit 2
```

本机复现 exit 2，与 QA 记录一致。

## 【根因】

`scripts/` 目录当前仅含 `dev-db.mjs`（无任何 `.ts` 文件），而 lint 命令/复现命令中的 `scripts/**/*.ts` glob 无匹配 → ESLint 以 exit 2 退出。属工程配置问题，非业务代码问题。

（另注：QA 复核时 package.json 的 lint 脚本在 M0-002 期间已移除 `scripts/**/*.ts`，但 `dev-db.mjs` 也因此未被纳入 lint 覆盖；本任务一并修正为正确覆盖。）

## 【修改文件】

- `apps/api/package.json`
- `apps/api/eslint.config.mjs`

仅此两文件，未改其他任何文件。

## 【修改内容】

1. `package.json`：lint 脚本由
   `eslint "src/**/*.ts" "test/**/*.ts"`
   改为
   `eslint "src/**/*.ts" "test/**/*.ts" "scripts/**/*.mjs"`
   ——当前 scripts/ 实际只有 `.mjs`，glob 与实际目录结构一致，不会再无匹配退出；且 `dev-db.mjs` 纳入真实 lint。

2. `eslint.config.mjs`：新增 `files: ['scripts/**/*.mjs']` 配置块，声明 Node 全局变量（`process`、`console` 为 readonly），避免对 Node 脚本的 no-undef 误报；未关闭任何规则、未扩大 ignore。

## 【lint覆盖范围】

- `src/**/*.ts`（44 个文件）：✅ 被 lint
- `test/**/*.ts`（3 个文件）：✅ 被 lint
- `scripts/**/*.mjs`（dev-db.mjs）：✅ 被 lint（反向验证见下）
- ignore 范围未变（仍仅 dist/node_modules/uploads/data/coverage），未整体忽略任何业务目录

反向验证（证明 dev-db.mjs 被真实检查而非跳过）：临时移除 globals 声明块后跑 `eslint "scripts/**/*.mjs"` → 14 个 `no-undef`（process/console）exit 1；恢复声明块后 exit 0。
