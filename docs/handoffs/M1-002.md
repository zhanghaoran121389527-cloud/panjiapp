### 4.1 auth/users 预置代码核对（契约 3.1/3.2/3.3）

逐项核对结果：**预置代码已完全符合契约，无需修改**（zero-diff 结论）：

| 契约点 | 实现现状 | 结论 |
|---|---|---|
| 3.1 请求 `phone` 11 位数字 | `DevLoginDto` `@Matches(/^\d{11}$/)` + trim transform | ✅ |
| 3.1 响应 200（非 201） | `@HttpCode(200)` 显式声明 | ✅ |
| 3.1 新号 isNewUser=true + token；老号 false | `AuthService.devLogin` 按 provider='dev'+identifier 查 auth_identities，无则事务建 user+identity | ✅ |
| 3.1 无短信 | 无任何短信依赖 | ✅ |
| 3.2 GET /v1/me → `{user:{id,nickname}}` | `UsersController.getMe` + `UsersService.getById`（用户不存在 404） | ✅ |
| 3.3 PATCH /v1/me 昵称 1~20 字 | `UpdateNicknameDto` trim + `@Length(1,20)` | ✅ |
| 3.x 无/坏 token → 401 AUTH_REQUIRED | 全局 `AuthGuard`（Bearer 解析 + JWT verify，失败统一 401） | ✅ |
| 生产门禁 | `NODE_ENV=production` 时 dev-login 抛 404 NOT_FOUND（不暴露路由存在性） | ✅ |

JWT：HS256、payload `{sub}`、365 天（app.module JwtModule 全局注册）✅。
