## 4. 完成内容

核对并确认预置 uploads 模块与 API_CONTRACT v2.3 §3.10 完全一致，仅做一处注释同步（零逻辑变更）：

| 契约要求（v2.3 §3.10） | 实现现状 | 结论 |
|---|---|---|
| 需登录（Bearer token） | 全局 AuthGuard（无 @Public），无 token → 401 AUTH_REQUIRED | ✅ |
| multipart 字段名 `file` | `FileInterceptor('file')` | ✅ |
| jpeg/png/heic/heif/webp 白名单 | mimetype 白名单（image/jpeg/png/heic/webp）+ 扩展名白名单（jpg/jpeg/png/heic/heif/webp）双校验 | ✅ |
| >10MB → UPLOAD_TOO_LARGE | multer `limits.fileSize=10MB` → Nest 转 PayloadTooLargeException → 全局过滤器 413 UPLOAD_TOO_LARGE | ✅ |
| uuid 重命名落本地 uploads/ | diskStorage，`randomUUID().<ext>`，目录启动时 mkdir | ✅ |
| 返回相对 URL | `{ "url": "/uploads/<uuid>.<ext>" }` | ✅ |
| GET /uploads/* 公开静态访问 | `useStaticAssets(uploadDir, { prefix: '/uploads' })`（应用级中间件，无鉴权拦截，公开可读） | ✅ |
| 不引第三方存储 SDK | 仅 multer（Nest 官方文件处理）+ 本地磁盘 | ✅ |

修改：`apps/api/src/modules/uploads/uploads.controller.ts` 注释更新为 v2.3 口径（提及 heif 与需登录），**无逻辑变化**。

## 12. 验收条件逐条证据（curl 自测，真实进程 127.0.0.1:3000）

```
1. 无 token 上传 png
   → HTTP 401 {"code":"AUTH_REQUIRED","message":"请先登录"}          ✅

2. 合法 png（Bearer token，-F "file=@test-upload.png;type=image/png"）
   → HTTP 201 {"url":"/uploads/eebf80d0-c931-4da5-9bf8-cc9be7236cab.png"}  ✅（uuid 重命名 .png）

3. 静态访问 GET /uploads/eebf80d0-…cab.png
   → HTTP 200 content-type=image/png                              ✅（公开访问）

4. 非图片 txt（type=text/plain）
   → HTTP 415 {"code":"UNSUPPORTED_TYPE","message":"仅支持 jpeg/png/heic/webp 图片"}  ✅

5. >10MB（11MB jpg，type=image/jpeg）
   → HTTP 413 {"code":"UPLOAD_TOO_LARGE","message":"图片大小不能超过 10MB"}  ✅

6. heif 扩展名（-F "file=@test-upload.heif;type=image/heic"）
   → HTTP 201 {"url":"/uploads/416a398e-….heif"}                  ✅（白名单含 heif）

7. 重启服务后 GET 同一 URL
   → HTTP 200 content-type=image/png                              ✅（本地磁盘持久化）
```

（测试用临时文件已清理；uploads/ 内本次产生的 2 个文件为验证产物，dev 环境可忽略/清理。）
