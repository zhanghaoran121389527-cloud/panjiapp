## 4. 使用 API（契约 v2.3）

| 接口 | 用途 |
|---|---|
| `POST /v1/auth/dev-login` | 登录；isNewUser 或 nickname 为空 → 昵称页，否则直进收藏柜 |
| `GET /v1/me` | 启动恢复登录态；401 → 清 token 回登录 |
| `PATCH /v1/me` | 设置昵称（1~20 字，客户端同规则预校验） |

错误处理：非 2xx 解析 `{code,message}` → APIError；401/`AUTH_REQUIRED` → 全局回登录不显示文案（08-states B 表）。

| 网络不可达/超时(10s) | 「网络不太顺畅，请检查后重试」 |
| VALIDATION_ERROR | 显示后端 message 原文 |
