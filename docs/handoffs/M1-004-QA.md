## 规格符合度（契约 3.10 逐项）

| 契约要求 | 实现（实读 uploads.controller.ts） | 独立实测 |
|---|---|---|
| 需登录（Bearer） | 无 @Public，全局 AuthGuard 默认保护 | **无 token 上传 → 401 `AUTH_REQUIRED`** ✓ |
| multipart 字段名 `file` | FileInterceptor('file') | curl `-F file=@…` 正常 ✓ |
| jpeg/png/heic/heif/webp 白名单 | mimetype（image/jpeg/png/heic/webp）+ 扩展名（jpg/jpeg/png/heic/heif/webp）双校验 | png 201 ✓；txt **415 UNSUPPORTED_TYPE** ✓；heif（type=image/heic）**201** ✓ |
| >10MB → UPLOAD_TOO_LARGE | multer limits 10MB → PayloadTooLarge → 全局过滤器 | 11MB → **413 `UPLOAD_TOO_LARGE`** ✓ |
| uuid 重命名落本地 uploads/ | diskStorage `randomUUID().<ext>` | 返回 `/uploads/a0cb922f-…png`（uuid4 + 原扩展名）✓ |
| 返回相对 URL | `{ "url": "/uploads/<uuid>.<ext>" }` | 201 body 全等格式 ✓ |
| GET /uploads/* 公开静态访问 | useStaticAssets(uploadDir, { prefix:'/uploads' })，应用级无鉴权 | **无 token GET → 200 content-type=image/png** ✓ |
| 重启后仍可访问（本地磁盘持久化） | 文件落盘 | **重启服务后同一 URL → 200**（png 与 heif 均复核）✓ |
| 不引第三方存储 SDK | 仅 multer + 本地磁盘 | package.json 无存储 SDK ✓ |
